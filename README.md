# Pranjal 💌

A small, interactive love-letter website made for Pranjal.

## Features

- Animated envelope that reveals the letter
- Relationship-day counter and milestones
- Flip cards for favourite things
- Interactive tulip and lily garden
- Optional playlist link
- Playful “Yes/No” question
- Birthday countdown
- Reduced-motion support and keyboard-accessible controls

## Run locally

No build step is required. Open `index.html` directly in a browser, or serve the folder with a local web server:

```bash
python3 -m http.server
```

Then visit <http://localhost:8000>.

## Personalise it

Edit the `CONFIG` object near the bottom of `index.html` to change:

- Names and dates
- Letter text and signature
- Favourite things
- Playlist URL
- Question and birthday message

## Deployment

This is a static site and can be deployed with GitHub Pages or any static hosting provider.
